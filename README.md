# 三目並べゲーム

シンプルで遊びやすいブラウザ向け三目並べゲーム。  
Live: https://design-pull.com/itportfolio/tic_tac_toe/  
Repo: https://github.com/design-pull/tic_tac_toe

## デモ
- ライブページ: https://design-pull.com/itportfolio/tic_tac_toe/
- スクリーンショット: `assets/` に画像を置いて埋め込めます

## 機能
- ローカルプレイ（X / O）
- スコアボード（X / O / 引き分け）
- 勝利演出（紙吹雪）
- レスポンシブ対応

## クイックスタート
```bash
git clone https://github.com/design-pull/tic_tac_toe.git
cd tic_tac_toe
# index.html をブラウザで開くか、簡易サーバで確認
